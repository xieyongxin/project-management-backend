# 第一期任务记录

本文件只记录开发任务的执行状态和依据，不擅自确定产品字段、接口、权限或数据库实现细节。

## 任务记录格式

```text
任务编号：PM-XXXX
关联 PRD：ACC-xx / AUTH-xx / ...
行为目标：一句话描述本轮唯一业务行为
范围：本轮允许修改的前后端区域
不包含：明确排除的相邻功能
验收条件：可观察、可复现的结果
状态：待开始 / 开发中 / 待验证 / 已完成 / 阻塞
后端提交：未提交或 commit hash
前端提交：未提交或 commit hash
验证记录：执行的命令、场景和结果
阻塞与待确认：需要用户决定的事项
```

## 任务约束

- 一个任务只对应一个可独立验收的业务行为。
- 同一行为需要前后端改动时，后端和前端使用相同任务编号分别提交。
- 任务不得把待确认决定写成默认实现。
- 任务完成必须填写验收结果和提交编号。
- 失败验证、跳过验证和未覆盖风险必须明确记录。
- 不得为了完成任务顺便加入无关重构、依赖升级或额外功能。
