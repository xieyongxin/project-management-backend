# PM-0020：读取任务两个内容版本并进行对比

状态：已完成

## 唯一业务行为

项目成员按任务版本 ID 读取两个不同的任务内容版本，接口按请求顺序返回左右版本，供前端展示版本差异。

## 关联依据

- PRD：`AUTH-07`、`TASK-07`、`TASK-08`、`TASK-09`
- 现有任务版本模型：`pm_task_version`

## 已实现验收条件

- `GET /project/{projectId}/tasks/{taskId}/versions/compare?leftVersionId={id}&rightVersionId={id}` 要求 `project:task:list` 权限。
- 两个版本必须属于同一个当前项目中的任务；项目成员可以读取，非成员和不存在的任务或版本返回 404。
- 两个版本 ID 相同时返回 400；版本 ID 格式非法返回 404。
- 响应包含 `left` 和 `right` 两个任务版本视图，并保持请求的左右顺序。
- 对比使用现有任务版本快照字段：标题、说明、依据的需求版本及创建信息；本轮不擅自定义页面差异展示或任务版本更新行为。
- 前端提供 `compareProjectTaskVersions` API 方法。
