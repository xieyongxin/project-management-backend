# PM-0035：按最新需求版本更新任务内容

## 目标

项目成员在任务详情确认更新操作后，修改任务标题和说明，并让新任务内容版本引用当前最新需求版本；旧任务版本继续保留可读和可对比。

## 实现边界

- 新增 `project:task:edit` 独立权限登记，权限由全局角色分配。
- 后端在事务内校验项目成员、项目状态、任务未删除、标题/说明和需求当前版本。
- 新版本沿用任务原有需求关系，依据读取到的需求当前版本；更新当前版本指针。
- 记录 `TASK_VERSION_UPDATE` 项目操作日志。
- 前端任务详情仅在拥有编辑权限且任务未删除时显示更新入口。

本轮不实现任务状态、分类、负责人编辑、附件、Agent、恢复、搜索排序或差异高亮。

## 验收与验证

- 单元测试覆盖正常版本生成、最新需求版本依据、无变化、非法字段、归档/删除/非成员、日志失败回滚。
- Controller 测试覆盖权限注解、参数校验、404 和业务错误映射。
- Maven 定向测试、前端生产构建和 `git diff --check` 通过。
- 真实 HTTP 验证成员更新、旧版本读取、需求版本切换后的新依据、无变化保存、空字段拒绝、非成员/归档/已删除拒绝和日志记录。

## 验收结果

- 后端 `TaskServiceImplTest` 20 项、`TaskControllerTest` 15 项通过。
- 后端 Maven 定向测试、前端 `npm run build:prod` 和 `git diff --check` 通过。
- `runtime/pm0035-http.cjs` 真实 HTTP 验收通过；临时项目、需求、任务、字典和角色权限映射已清理。
