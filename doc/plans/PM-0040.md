# PM-0040：普通字段编辑

## 目标

具备项目编辑权限的项目成员可以修改当前项目内需求负责人、任务分类和任务负责人；这些字段不生成内容版本，实际变化写入项目操作日志。

## 实现范围

- 需求负责人更新接口：`project:requirement:edit`。
- 任务分类和负责人更新接口：`project:task:edit` 或 `project:agent:split`。
- 校验项目成员、归档项目、逻辑删除记录、有效任务分类和负责人成员资格。
- 关联表事务更新，重复保存不新增日志；实际变化分别记录 `REQUIREMENT_OWNER_UPDATE`、`TASK_FIELD_UPDATE`。
- 需求详情和任务详情增加受权限控制的编辑弹窗。

## 验收结果

- 后端完整测试：`mvn -B -ntp -pl ruoyi-system,ruoyi-admin -am test`，system 77 项、admin 62 项全部通过。
- 后端增量编译通过；前端 `npm run build:prod` 和 `git diff --check` 通过。
- 内容版本更新接口和普通字段接口分别保持版本职责：负责人、分类变化不新增需求/任务内容版本。
