# PM-0014：读取项目需求详情和版本历史

状态：验收通过

## 唯一业务行为

项目成员读取当前项目中的一条需求详情及其内容版本列表；需求详情返回当前版本标识，版本列表按版本号稳定升序返回。

## 已实现验收条件

- 需求详情和版本历史接口均要求 `project:requirement:list` 权限。
- 项目成员可以读取属于当前项目且未逻辑删除的需求详情和版本历史。
- 非项目成员、其他项目需求、逻辑删除需求、不存在需求和非法 ID 均返回 404，且不泄露需求内容。
- 版本历史返回标题、正文、附件清单快照、创建人、创建时间和版本号。
- 版本结果按 `version_no`、`version_id` 升序排列，详情返回 `currentVersionId`。
- 本轮只提供读取 API 和前端 API 方法，不实现编辑、版本更新、版本对比 UI、附件上传下载或需求创建页面。

## 修改范围

- 后端需求 Mapper、Service、Controller、详情/版本视图对象及测试。
- 前端项目 API：`getProjectRequirement`、`listProjectRequirementVersions`。
- 本轮不新增数据库表、字段或迁移脚本。
