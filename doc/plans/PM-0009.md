# PM-0009：项目归档与重新启用基础状态

状态：已完成

## 唯一业务行为

项目管理员可以将项目标记为归档或重新启用；归档项目保留成员、角色和历史查询能力，并拒绝新的项目名称修改。

## PRD 对应条目

- `PROJ-03`、`PROJ-07`、`PROJ-08`

## 本轮范围

- `pm_project.status` 增量字段，默认 `ACTIVE`。
- 管理员状态接口：`PUT /project/{projectId}/status`，请求体 `{ archived: true|false }`。
- 项目详情和列表返回并显示状态。
- 归档项目拒绝项目名称修改。
- 归档期间保留成员名册、项目角色管理和项目日志读取。

## 明确不包含

- 归档确认弹窗和具体前端操作按钮。
- 归档/启用是否写项目操作日志。
- 归档时未结束任务的处理。
- 需求、任务、附件等后续模块的归档限制。
