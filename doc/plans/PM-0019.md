# PM-0019：项目成员修改需求状态并记录项目日志

状态：已完成

## 唯一业务行为

具有独立状态修改权限的项目成员修改当前项目需求状态；状态变化只更新需求普通字段并写入项目操作日志，不生成新的需求内容版本。

## 关联依据

- PRD：`AUTH-07`、`AUTH-08`、`DICT-04`、`PROJ-07`、`REQ-03`、`REQ-05`、`REQ-09`、`LOG-01`
- 增量迁移：`sql/pm_0019_requirement_status.sql`

## 已实现验收条件

- `PUT /project/{projectId}/requirements/{requirementId}/status` 要求 `project:requirement:status` 权限。
- 后端按项目成员关系隔离需求；非成员、非法需求和非法 ID 返回 404。
- 归档项目拒绝新的需求状态修改。
- 只能使用当前有效需求状态；状态流转顺序不限制，状态未变化时不更新数据库、不增加版本、不写日志。
- 状态变化只更新 `pm_requirement.status` 和更新时间，写入 `REQUIREMENT_STATUS_UPDATE` 项目日志，不生成需求内容版本。
- 状态更新和项目日志在同一事务中，日志失败时需求状态回滚。
- 前端提供 `updateProjectRequirementStatus` API 方法，后端权限校验为最终边界。
