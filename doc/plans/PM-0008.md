# PM-0008：按项目权限查询操作日志

状态：已完成

## 唯一业务行为

拥有独立日志查看权限且属于项目的用户，可以分页查询项目操作日志。查询结果只包含项目范围内的必要审计字段。

## PRD 对应条目

- `LOG-01`、`LOG-02`、`LOG-03`、`AUTH-07`

## 不包含

- AI 调用记录和完整 AI 输入输出。
- 需求/任务日志查询。
- 全局角色与日志权限的具体映射。

## 验收条件

- 项目成员且拥有 `project:log:list` 权限时可以分页查询日志。
- 无日志权限返回 403，非项目成员返回 404。
- 返回操作者、目标成员、项目、操作类型、说明和操作时间。
- 查询严格按项目隔离。

## 实现与验证记录

- 后端新增项目范围日志查询 Mapper、服务方法、`GET /project/{projectId}/logs` 接口和 `project:log:list` 权限登记脚本；查询结果显式映射日志 ID、项目 ID、操作者、目标成员、操作类型、说明和时间。
- 前端项目详情页新增按权限显示的日志表、分页、刷新和错误提示。

- 前端构建：`npm run build:prod` 通过。
- 本地真实 HTTP：管理员查询项目 1 返回 200 和分页日志字段；非法项目返回 404；临时改名生成的两条日志已清理。
