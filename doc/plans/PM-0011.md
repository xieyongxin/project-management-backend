# PM-0011：项目管理员添加成员并绑定全局角色

状态：验收通过

## 唯一业务行为

项目管理员按已注册用户 ID 添加项目成员，并在加入时绑定一个有效的若依全局角色；成功后成员关系立即生效。

## 验收条件

- 项目管理员可以添加有效用户并绑定有效全局角色。
- 新成员立即出现在项目成员名册中，且带有请求指定的角色。
- 非管理员返回 403，非成员返回 404。
- 未注册、停用或已删除用户不能加入；无效或停用角色不能使用。
- 已是项目成员的用户不能重复加入。
- 添加成员和 `MEMBER_ADD` 项目日志写入在同一事务中，日志失败时成员关系回滚。
- 归档项目仍允许管理员添加成员，符合现有归档管理规则。

## 不包含

- 用户名、昵称、邮箱搜索匹配方式、结果数量和分页。
- 前端搜索下拉交互；待产品确认搜索规则后单独实现。
- 需求、任务、附件、版本、Agent 和成员恢复。
