# PM-0004：项目成员名册只读查看

状态：验收通过

## 唯一业务行为

项目成员可以查看当前项目成员名册；名册显示用户基本资料、绑定的若依全局角色和项目管理员标记。

## PRD 对应条目

- `AUTH-04`、`AUTH-07`、`AUTH-11`、`PROJ-02`

## 范围

- 项目成员关系增加可选 `role_id`，直接引用若依全局角色。
- 新增成员名册查询接口，查询本身通过当前用户项目成员关系隔离。
- 前端项目详情展示用户名、昵称、邮箱、全局角色名和项目管理员标记。
- 成员名册失败提供重试入口；非成员和不存在项目统一返回 HTTP 404。

## 不包含

- 添加、移除成员。
- 角色调整和项目管理员资格调整。
- 用户搜索、搜索匹配方式、结果数量和分页设计。

## 验收条件

- 项目成员可以读取该项目全部成员的名册信息。
- 创建者可以没有全局角色，角色名为空时前端显示“未设置”。
- 非项目成员、超级管理员无成员关系和不存在项目均不能读取名册，并返回 404。
- 非法项目 ID 返回 404，且不查询业务服务。
- 后端 MyBatis 映射、事务服务和控制器测试通过；前端生产构建通过。
