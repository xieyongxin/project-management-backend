# PM-0021：读取需求两个内容版本并进行对比

状态：已完成

## 唯一业务行为

项目成员按需求版本 ID 读取两个不同的需求内容版本，接口按请求顺序返回左右版本，供前端展示标题、正文和附件快照差异。

## 关联依据

- PRD：`AUTH-07`、`REQ-04`、`REQ-07`、`REQ-09`
- 现有需求版本模型：`pm_requirement_version`

## 已实现验收条件

- `GET /project/{projectId}/requirements/{requirementId}/versions/compare?leftVersionId={id}&rightVersionId={id}` 要求 `project:requirement:list` 权限。
- 两个版本必须属于同一个当前项目中的需求；项目成员可以读取，非成员和不存在的需求或版本返回 404。
- 两个版本 ID 相同时返回 400；版本 ID 格式非法返回 404。
- 响应包含 `left` 和 `right` 两个需求版本视图，并保持请求的左右顺序。
- 对比使用现有需求版本快照字段：标题、正文、附件快照及创建信息；本轮不擅自定义页面差异展示、附件访问规则或需求编辑行为。
- 前端提供 `compareProjectRequirementVersions` API 方法。
