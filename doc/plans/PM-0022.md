# PM-0022：负责人引用阻止移除项目成员

状态：已完成

## 唯一业务行为

项目管理员移除项目成员时，若该成员仍是当前项目任一未删除需求或任务的负责人，移除被拒绝并保留成员关系。

## 关联依据

- PRD：`PROJ-03`、`PROJ-06`、`AUTH-07`
- 现有引用关系：`pm_requirement_owner`、`pm_task_owner`

## 已实现验收条件

- 需求负责人仍被引用时，成员移除返回 HTTP 400。
- 任务负责人仍被引用时，成员移除返回 HTTP 400。
- 引用检查按项目隔离，并忽略已逻辑删除的需求和任务。
- 拒绝移除时成员关系和项目日志不发生变化。
- 前端沿用已有移除接口的 400 业务错误处理，直接显示后端返回的阻断原因。

## 修改范围

- 后端项目服务测试和控制器测试，补齐需求/任务负责人引用阻断的验收证据。
- 前端本轮无源代码改动；已有 `removeProjectMember` API 和项目详情错误提示覆盖该业务错误。
- 任务记录与本验收计划文档。
