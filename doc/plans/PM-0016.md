# PM-0016：项目成员分页查看任务列表

状态：已完成

## 唯一业务行为

项目成员从项目详情进入任务列表，按页查看当前项目的任务基础信息、需求版本依据和负责人。

## 已实现验收条件

- 项目详情在用户拥有 `project:task:list` 权限或超级权限时显示任务列表入口。
- 任务列表使用隐藏路由，支持基础分页、空列表、加载失败重试和项目无权访问提示。
- 列表显示任务编号、标题、状态、当前版本、依据需求及版本、分类、负责人和更新时间。
- 后端列表接口按项目成员关系隔离；非成员、不存在项目和非法项目访问返回 404。
- 列表按 `create_time desc, task_id desc` 稳定排序，分页查询不会消耗项目成员资格校验的分页上下文。
- 本轮只登记 `project:task:list` 权限，不新增默认任务状态和分类值。

## 不包含

- 任务创建页面、任务详情、编辑、版本更新/对比、删除、附件、Agent、搜索和排序交互。
- 未确认的任务页面布局、状态/分类初始清单和后续任务入口。

## 修改范围

- 后端任务列表 Mapper、Service、Controller、权限增量脚本和单元测试。
- 前端任务列表 API、项目详情入口、隐藏路由和分页列表页面。
