# PM-0027：角色状态变更后立即刷新在线用户权限

状态：验收通过

## 唯一业务行为

全局角色启用或停用后，已经登录且持有该角色的项目成员立即按最新角色状态计算权限；角色恢复启用后，权限立即恢复。其他角色用户和超级管理员行为保持不变。

## 关联依据

- PRD：`AUTH-01`、`AUTH-02`、`AUTH-07`
- 相关已有行为：若依全局角色管理、PM-0005、PM-0011

## 范围

- 角色状态修改成功后刷新所有在线用户的权限缓存。
- 刷新时重新读取用户当前角色列表，避免 Redis 中缓存的旧角色状态继续生效。
- 角色状态修改失败时不刷新权限。
- 增加控制器和 TokenService 单元测试，覆盖成功/失败分支及角色状态重新读取。

不包含：普通编辑权限范围、全局角色到项目权限的详细映射、项目业务数据改造、前端角色页面改造和数据库结构迁移。

## 验收条件

- 在线用户持有的角色停用后，立即访问受该角色权限保护的接口返回无权限。
- 该角色重新启用后，同一在线用户立即恢复访问权限。
- 不持有该角色的用户不受影响。
- 角色状态更新失败时不触发在线权限刷新。
- 超级管理员不因角色状态刷新而失去管理员权限。
