
# PM-0039：Agent 失败记录与人工重试

## 目标

Agent 适配器不可用或调用失败时保存失败调用记录及完整输入快照；项目成员确认后可以基于同一份输入重试，重试记录保留来源调用、需求版本和重试次数。

## 实现范围

- `pm_agent_call` 增加重试来源、重试次数和发送时需求标题快照字段。
- 未配置可用适配器时写入 `FAILED` 状态和失败原因，并记录 `AGENT_CALL` 项目日志。
- 新增受 `project:agent:split` 保护的失败调用重试接口；重试沿用原需求版本、正文、附件快照和解析快照。
- 读取调用记录页面展示重试次数；失败记录提供确认后重试入口。
- 最大重试次数继续由 `project.agent.retry.max` 服务端配置控制；每次重试使用新的幂等键。
