# PM-0018：项目成员修改任务状态并记录项目日志

状态：已完成

## 唯一业务行为

具有独立状态修改权限的项目成员修改当前项目任务状态；状态变化更新任务普通字段并写入项目操作日志，不能生成新的任务内容版本。

## 关联依据

- PRD：`AUTH-07`、`AUTH-08`、`DICT-04`、`PROJ-07`、`TASK-07`、`LOG-01`
- 增量迁移：`sql/pm_0018_task_status.sql`

## 已实现验收条件

- `PUT /project/{projectId}/tasks/{taskId}/status` 要求 `project:task:status` 权限。
- 后端按项目成员关系隔离任务；非成员、非法任务和非法 ID 返回 404。
- 归档项目拒绝新的任务状态修改。
- 只能使用当前有效任务状态；状态流转顺序不限制，状态未变化时不更新数据库、不增加版本、不写日志。
- 状态变化只更新 `pm_task.status` 和更新时间，写入 `TASK_STATUS_UPDATE` 项目日志，不生成任务内容版本。
- 状态更新和项目日志在同一事务中，日志失败时任务状态回滚。
- 前端提供 `updateProjectTaskStatus` API 方法，保留后端权限校验为最终边界。
