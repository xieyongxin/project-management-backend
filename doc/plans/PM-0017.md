# PM-0017：读取项目任务详情和版本历史

状态：已完成

## 唯一业务行为

项目成员读取当前项目中的一条任务详情及其任务内容版本列表；详情返回当前任务版本和各版本的需求版本依据。

## 已实现验收条件

- 任务详情和版本历史接口均要求 `project:task:list` 权限。
- 项目成员可以读取属于当前项目且未逻辑删除的任务详情和版本历史。
- 非项目成员、其他项目任务、不存在任务和非法 ID 均返回 404，且不泄露任务内容。
- 任务详情返回当前任务版本、状态、分类、负责人和需求版本依据。
- 版本历史返回标题、说明、任务版本号、依据的需求版本 ID/版本号、创建人和创建时间。
- 版本结果按 `version_no`、`version_id` 升序排列。
- 本轮只提供读取 API 和前端 API 方法，不实现任务编辑、版本更新入口、版本对比 UI、删除、附件或 Agent。

## 修改范围

- 后端任务版本字段、Mapper、Service、Controller、版本视图对象及测试。
- 前端项目 API：`getProjectTask`、`listProjectTaskVersions`。
