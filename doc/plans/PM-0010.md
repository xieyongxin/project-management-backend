# PM-0010：项目管理员移除项目成员

状态：已完成

## 唯一业务行为

项目管理员可以移除已有项目成员；移除立即生效，并记录项目操作日志。

## 验收条件

- 项目管理员可以移除其他项目成员，成员关系立即删除。
- 非管理员返回 403，非成员或不存在的目标成员返回 404。
- 项目至少保留一名项目管理员，不能移除最后一名管理员。
- 成员移除和操作日志写入在同一事务中，日志写入失败时成员关系保留。
- 归档项目仍允许项目管理员管理成员。
- 需求和任务模块建立后，仍被负责人引用的成员必须被拒绝移除；本轮不提前创建需求、任务表，后续模块接入负责人引用检查。

## 不包含

- 用户搜索和成员添加；其搜索匹配、结果数量和分页仍待产品确认。
- 需求、任务、附件、版本和 Agent 功能。
- 项目删除、永久删除和成员恢复。

## 预计修改范围

- 后端项目成员删除接口、服务事务、项目日志和相关测试。
- 前端项目详情成员操作列、确认提示、删除 API 和错误处理。
- `doc/TASKS.md` 验收记录。

## 依赖和边界

PM-0010 不新增数据库表或字段，复用 `pm_project_member` 和项目操作日志表。需求/任务负责人阻断需要在对应模块落地时接入同一删除服务的引用检查，不以当前不存在的表名实现隐式产品语义。
