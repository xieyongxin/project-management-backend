
# PM-0038：查询 Agent 调用记录入口

## 目标

拥有独立 `project:agent:log` 权限且属于项目的成员，可以从需求详情打开 Agent 调用记录，查看该需求的调用状态、确认时锁定的需求版本、附件快照、实际输入、解析结果、任务草稿和失败原因。

## 实现范围

- 复用 PM-0037 已完成的项目隔离和 `project:agent:log` 权限接口。
- 前端需求详情增加调用记录入口和展开详情。
- 记录加载失败时显示重试入口；无记录时显示空状态。
- 不新增调用记录字段、重试行为、配置管理或搜索字段。

## 验收条件

- 有 `project:agent:log` 权限的项目成员可以打开需求详情中的 Agent 调用记录并读取当前需求的记录。
- 每条记录显示调用编号、锁定需求版本、服务商/模型、状态、是否允许外发和调用时间；展开后可以查看附件快照、正文、解析结果、任务草稿和失败原因。
- 无日志权限的成员看不到入口；即使直接请求接口仍由后端权限校验拒绝。
- 非项目成员或不存在需求不会通过前端入口读取记录，后端仍返回项目隔离语义。
- 请求失败显示错误和重试入口，空列表显示明确空状态。

## 验证记录

- 前端生产构建和 `git diff --check` 通过。
- 已核对调用记录接口仍使用 `@PreAuthorize('project:agent:log')`，服务层同时校验项目成员和需求访问边界；本轮未修改后端业务接口或数据库。
