# PM-0007：项目管理员修改项目名称

状态：验收通过

## 唯一业务行为

项目管理员可以修改当前项目名称。名称先去首尾空格，再按现有项目名称规范化唯一键判断重复；改名与项目操作日志在同一事务中完成。

## PRD 对应条目

- `PROJ-03`、`PROJ-09`、`LOG-01`

## 不包含

- 归档和重新启用项目。
- 成员、需求、任务和项目日志查询。
- 归档项目改名策略（产品待确认）。

## 验收条件

- 管理员可修改项目名称并返回更新后的项目。
- 普通成员返回 403，非成员返回 404。
- 空白或超过 255 个字符返回 400；规范化重名返回 409 且原名称保留。
- 改名和日志写入在同一事务中；日志失败时改名回滚。
- 前端管理员可编辑，普通成员只读显示。

- `npm run build:prod`：通过。

- 验证结束后将项目 1 恢复为 `APILink`，删除临时项目、成员和日志；测试库最终项目成员总数为 1、项目日志总数为 0。
