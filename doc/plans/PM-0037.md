# PM-0037：Agent 辅助拆分任务

## 目标

项目成员确认需求正文和附件后调用可配置 Agent，锁定确认时需求版本，保存可审计的调用记录和可编辑任务草稿。正式任务只能由用户补充必填字段后手工保存。

## 实现范围

- Agent 预览和确认接口，确认前不创建调用记录。
- 服务端配置：服务商、模型、密钥、是否外发、附件解析开关和最大字符数、超时、重试、幂等、限流、费用和日志留存参数。
- 调用时保存需求版本、正文、所选附件快照、附件解析结果、草稿和状态。
- 项目级 `AGENT_CALL` 日志和独立 `project:agent:log` 调用记录查询权限。
- Agent 权限联动任务创建和任务最新版本编辑接口；前端草稿编辑、删除和批量保存。
- 默认使用本地草稿适配器，`project.agent.external.enabled=false`，不向第三方发送数据。
