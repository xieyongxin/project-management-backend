# PM-0012：创建项目需求基础记录

状态：验收通过

## 唯一业务行为

项目成员在当前项目中创建一条需求，填写标题、富文本正文、一个有效需求状态，并选择至少一名当前项目成员作为负责人；创建时生成第一个内容版本并记录项目操作日志。

## 已实现验收条件

- 非项目成员不能读取需求列表或状态选项，返回与项目不存在一致的 404。
- 归档项目拒绝创建新需求。
- 标题为空、正文为空、富文本只含空标签、状态为空或负责人为空时拒绝保存。
- 只能选择当前项目成员作为负责人，重复负责人 ID 会去重。
- 只能使用启用的 `pm_requirement_status` 字典值；本轮不插入未确认的默认状态。
- 创建需求、第一版内容、负责人关系和 `REQUIREMENT_CREATE` 日志在同一事务中写入；日志失败时全部回滚。
- 需求列表按创建时间和需求 ID 稳定倒序。
- 移除成员前检查其是否仍是当前项目需求负责人。

## 不包含

- 需求编辑、负责人或状态修改。
- 内容版本更新、版本列表、版本对比和需求删除。
- 附件上传、私有附件访问和附件清单变化判断。
- 任务、Agent 和未确认的富文本或页面交互方案。
- 需求状态初始值；管理员需通过若依字典维护 `pm_requirement_status`。
